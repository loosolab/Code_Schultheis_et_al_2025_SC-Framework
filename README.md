# SC-Framework: A robust and FAIR semi-interactive environment for single-cell resolution datasets

[![Static Badge](https://img.shields.io/badge/bioRxiv-10.1101%2F2025.11.11.687874-%23bd2736)](https://doi.org/10.1101/2025.11.11.687874)

This repository contains all the code to reproduce the analysis of the SC-Framework paper.

# Abstract
The development of single-cell technologies has profoundly impacted biological research by facilitating novel insights into cellular heterogeneity. This progress has produced bioinformatic challenges: single-cell datasets are increasingly high-dimensional, multimodal, and large-scale, while analysis workflows remain fragmented, data type specific, ad hoc, and irreproducible. The prevailing methodologies are dependent on a combination of complex tools, which reduces scalability and interoperability between analyses. A higher-level, unified framework for single-cell data analysis is required to overcome current limitations.
Here, we introduce the SC-Framework to provide integration of standardized data structures via declarative workflows. Containerized environments with pre-defined analyses enable users to focus on biological interpretation rather than technical overhead. The SC-Framework is available at [GitHub](https://github.com/loosolab/SC-Framework).

# Getting started
Follow the instructions to install the SC-Framework from [here](https://github.com/loosolab/SC-Framework). Then open one of the folders (`RNA` or `ATAC`) open `analysis` and follow the notebook execution order described in the respective README.
