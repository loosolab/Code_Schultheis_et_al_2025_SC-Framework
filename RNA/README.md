Zebrafish cranial scRNA timepoints are individually analyzed using the core notebooks (assembly -> QC -> batch and normalization -> embedding and clustering) with added downstream analysis of marker identification and cluster annotation. Timepoint 150 dpf is further analyzed using GSEA followed by receptor-ligand analysis. A separate run combines the core analysis results of 5 and 14 dpf to create a detailed embedding and clustering (assembly -> batch and normalization -> embedding and clustering) to identify and split the data into jaw and gill related cell types. Both subsets are re-analyzed (assembly -> batch and normalization -> embedding and clustering) followed by pseudotime analysis. Another run combines the core results of the timepoints and a new embedding and clustering is computed using the assembly, batch and normalization, and embedding and clustering notebooks. The results are further processed using the marker identification, cluster annotation, proportion analysis, receptor-ligand and cellxgene preparation notebooks.
Similar to RNA, snATAC timepoints are individually analyzed using the respective ATAC core notebooks (assembly -> QC -> normalization and batch correction -> embedding and clustering).
